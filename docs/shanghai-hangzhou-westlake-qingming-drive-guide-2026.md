## 🗺️ 路线规划

### 上海 → 杭州西湖（推荐路线）

```
上海市区
    ↓
沪杭高速 (G60)
    ↓
德胜/彭埠出口
    ↓
德胜快速路
    ↓
环城西路
    ↓
省人民大会堂停车场（推荐）
```

| 项目 | 详情 |
|------|------|
| 总里程 | 约 180 公里 |
| 预计时间 | 2.5-3 小时（不堵车） |
| 高速费 | 约 80-100 元 |
| 最佳出发时间 | 6:00 前 |

### Alternative 路线对比

| 路线 | 优点 | 缺点 | 适合人群 |
|------|------|------|----------|
| 沪杭高速 (G60) | 路况好、速度快 | 清明可能拥堵 | 大多数游客 |
| 沪昆高速 | 车流量相对少 | 距离稍远 | 避开高峰 |
| 杭浦高速 | 直达北线景点 | 下高速后易堵 | 去灵隐方向 |

## 🅿️ 停车攻略

### 核心策略

**❌ 不建议直接开进景区**
- 单双号限行（8:00-17:00）
- 灵隐/南山路需"西湖通"
- 停车费 20 元/小时（贵 3 倍）
- 车位极少，堵车找车位

**✅ 推荐停外围换乘**
- 不限行
- 停车费便宜
- 有公交接驳
- 省心省力

### 📍 省人民大会堂停车场（首选推荐）

```
📍 导航：浙江省人民大会堂停车场
🚪 出入口：环城西路、省府路、凤起路
🚗 车位：1378 个（地面 + 地下）
💰 收费：7 元/小时，42 元/天封顶
⏰ 营业时间：24 小时
🚶 到断桥：步行 5-10 分钟
🚌 接驳：277 路区间（东门环城西路）
```

**接驳线路：**
```
省人民大会堂 → 断桥 → 白堤 → 岳王庙 → 西泠桥 → 西溪湿地
```

**优势：**
- ✅ 离西湖最近（步行 5 分钟到断桥）
- ✅ 价格最良心（42 元封顶 vs 景区 20 元/小时）
- ✅ 车位最多（1378 个）
- ✅ 官方推荐换乘点

## ⚠️ 注意事项

### 交通规则

| 规定 | 时间 | 处罚 |
|------|------|------|
| 单双号限行 | 每天 8:00-17:00 | 100 元 +3 分 |
| 西湖通 | 去灵隐/南山路必需 | 100 元 +3 分 |
| 景区限行 | 全天 | 100 元 +3 分 |

### "西湖通"申领指南

```
入口：支付宝 → 市民中心 → 交警 → 西湖通
     或 警察叔叔 APP → 西湖通
时间：提前 1 天申领（当天办不了）
限制：每月每车限 1 次
费用：免费
```

### 避坑指南

| 坑 | 避免方法 |
|----|----------|
| 景区停车贵 | 停外围换乘 |
| 堵车找车位 | 8 点前到停车场 |
| 单双号限行 | 提前检查车牌 |
| 灵隐进不去 | 提前申领"西湖通" |
| 排队坐船久 | 早上去或傍晚去 |
| 龙井茶被宰 | 去正规茶庄 |
| 景区餐饮贵 | 带点干粮或去市区吃 |

## ✅ 行前检查清单

```
□ 检查车牌单双号（尾号与日期一致）

□ 查看天气预报

□ 准备干粮和水

□ 手机充满电
```
