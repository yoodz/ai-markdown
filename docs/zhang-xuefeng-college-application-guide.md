# 张雪峰高考志愿填报思想全解析

> 整理日期：2026-04-03  
> 适用人群：普通家庭考生、志愿填报迷茫者

---

## 🎯 核心思想

**"把高考志愿当成职业规划来做"**

张雪峰认为，高考志愿填报不是简单的选学校、选专业，而是**人生职业规划的第一步**。

### 核心主张

| 主张 | 说明 |
|------|------|
| **就业导向** | 专业选择要考虑未来就业，不是凭兴趣盲目选 |
| **城市优先** | 一线城市 > 二线城市，实习机会、视野、人脉都更重要 |
| **学校层次** | 能上 985 不上 211，能上 211 不上双非（普通本科） |
| **专业壁垒** | 选有技术壁垒的专业，避免"万金油"专业 |

### 报考逻辑（优先级排序）

```
城市 > 学校 > 专业
```

| 优先级 | 考量因素 | 理由 |
|--------|---------|------|
| 1️⃣ 城市 | 一线/新一线优先 | 实习机会多、视野开阔、人脉资源、就业面广 |
| 2️⃣ 学校 | 985/211/双一流 | 学历是敲门砖，很多大厂/国企卡学历 |
| 3️⃣ 专业 | 有技术壁垒的 | 计算机、法学、医学、电气等，避免被替代 |

## 📋 报考建议（如何操作）

### 1️⃣ 先定城市

**首选城市：** 北京、上海、广州、深圳、杭州、成都、武汉

**理由：** 大学四年积累的人脉和实习经历，很可能决定你毕业后留在哪里

### 2️⃣ 再定学校层次

- 分数够 985 就不去 211
- 分数够 211 就不去双非
- 同层次学校选城市更好的

### 3️⃣ 最后定专业

#### 推荐专业（有壁垒）

| 专业 | 就业方向 | 备注 |
|------|---------|------|
| 计算机/软件/人工智能 | 互联网大厂、科技公司 | 再卷也有就业机会 |
| 法学（五院四系） | 律所、公检法、法务 | 必须通过法考 |
| 医学（临床、口腔） | 医院、医疗机构 | 周期长，越老越吃香 |
| 电气工程 | 国家电网、电力系统 | 稳定，待遇好 |
| 师范类（公费师范生） | 教师编制 | 毕业有编有岗 |

#### 谨慎选择

| 专业 | 原因 |
|------|------|
| 工商管理、市场营销 | 学的太泛，不如工作经验 |
| 生物、化学、环境、材料 | "生化环材"，本科就业难 |
| 新闻传播 | 被 AI 冲击大 |
| 小语种 | 除非顶尖院校，否则就业面窄 |
| 心理学 | 国内就业面窄，需要深造 |
| 哲学/历史/社会学 | 真爱 + 家里有矿 |

### 4️⃣ 特殊路径

| 路径 | 适合人群 | 说明 |
|------|---------|------|
| **公费师范生** | 求稳、想当老师 | 毕业有编有岗 |
| **军校/警校** | 能吃苦、想进体制 | 包分配，管理严格 |
| **强基计划** | 想搞科研 | 基础学科，本硕博连读 |
| **中外合作办学** | 分数不够但想上好学校 | 学费贵，家里有钱可以考虑 |

## 🎯 专业选择的"三不报"原则

| 原则 | 解释 | 例子 |
|------|------|------|
| **不报家里没资源的专业** | 需要人脉/资金堆出来的专业 | 金融、艺术、管理、新闻 |
| **不报本科无法就业的专业** | 必须读研读博才有出路的 | 生物、化学、材料、环境 |
| **不报被替代性强的专业** | AI/自动化冲击大的 | 会计、翻译、文秘、部分设计 |

## 🔥 专业鄙视链

### 顶层（闭眼报）

- 计算机（互联网大厂）
- 临床医学（医生越老越吃香）
- 法学（五院四系→律所/公检法）
- 电气工程（国家电网）

### 中层（看学校）

- 师范类（公费师范生＞普通师范）
- 财经类（两财一贸＞普通财经）
- 电子信息（硬件/芯片方向）

### 底层（谨慎）

- 工商管理（学的太泛，不如工作经验）
- 国际贸易（英语好 + 专业好才行）
- 心理学（国内就业面窄）
- 哲学/历史/社会学（真爱 + 家里有矿）

## ⚠️ 常见误区（他经常怼的）

| 误区 | 张雪峰的观点 |
|------|-------------|
| "孩子喜欢就行" | 18 岁的孩子懂什么喜欢？见过世面再谈兴趣 |
| "先上大学再说" | 选错专业转专业很难，很多学校限制成绩前 10% |
| "考研可以换专业" | 跨专业考研成功率极低，复试容易被刷 |
| "名校冷门专业也好" | 校招时 HR 看专业匹配度，名校也救不了 |
| "学什么都一样" | 不一样，有些专业起薪 3 千，有些 3 万 |

## 📊 报考"三步法"

```
1. 算位次 → 不看分数看排名（每年分数线波动，位次更准）
2. 圈范围 → 位次±2000 名的学校都列出来
3. 做减法 → 按城市→学校→专业优先级筛选
```

### 具体操作

| 策略 | 学校数量 | 说明 |
|------|---------|------|
| **冲** | 2-3 个志愿 | 位次高 10-15% 的学校 |
| **稳** | 4-5 个志愿 | 位次匹配的学校 |
| **保** | 2-3 个志愿 | 位次低 10-15% 的学校 |

## 💰 关于考研的观点

- **"能保研不考研，能考研不考公"**（除非想进体制）
- **"计算机本科就能就业，生物博士都难找工作"**
- **"考研选学校比选专业重要，导师比学校更重要"**
- **"不要为了逃避就业而考研，三年后还是要面对"**

## 🎯 适合人群分析

### 张雪峰思想适合谁

| 适合 ✅ | 不适合 ❌ |
|--------|----------|
| 普通工薪家庭 | 家里有资源/人脉的 |
| 第一目标：好就业 | 有明确学术/艺术追求的 |
| 没人指导的农村/县城家庭 | 对某个领域有热爱的 |
| 求稳，想进体制 | 想创业/自由职业的 |
| 分数中等，容错率低 | 分数顶尖，选择面广的 |

### 关于"穷孩子"的特别建议

1. **优先选能尽快赚钱的专业** - 计算机＞金融＞管理
2. **考虑学费和生活成本** - 中外合作一年 10 万+，普通家庭扛不住
3. **公费师范生/军校是捷径** - 毕业有编有岗，家里不用托关系
4. **不要盲目追求"体面专业"** - 好就业比好听重要

## 🔍 锐评与争议

### ✅ 他对在哪

| 维度 | 评价 |
|------|------|
| **打破信息差** | 普通家庭真不知道哪些专业坑，他敢说真话 |
| **就业导向** | 对没试错成本的家庭，生存优先没毛病 |
| **怼醒理想主义** | 18 岁小孩谈兴趣确实容易翻车 |
| **实操性强** | 位次法、冲稳保，直接能用 |

**核心价值：** 他是**底层家庭的志愿填报"避坑指南"**，让没资源的孩子少踩雷。

### ❌ 他问题在哪

| 问题 | 说明 |
|------|------|
| **过于功利** | 把大学当成职业培训所，忽视通识教育和人的全面发展 |
| **路径依赖** | 推荐的专业（计算机/法学/医学）已经卷成红海，他说的还是几年前的行情 |
| **一刀切** | "生化环材"不能报？那国家基础科研谁做？适合的人就被他劝退了 |
| **城市决定论** | 一线城市确实机会多，但生活成本、落户难度他不提 |
| **幸存者偏差** | 他看到的案例都是来找他咨询的，本身就有选择性 |

### 💬 争议点

1. **"兴趣不能当饭吃"** — 但没兴趣的工作，干一辈子不痛苦吗？
2. **"计算机闭眼报"** — 2024 年开始互联网裁员潮，他还在推
3. **"生化环材是天坑"** — 新能源、半导体起来后，材料/化学需求大涨
4. **"考研不如早点工作"** — 但很多岗位硕士是门槛，他自相矛盾

## 🧠 综合评价

**张雪峰是"乱世用重典"的志愿填报顾问。**

- 在**信息极度不对称**的环境里，他的极端观点反而能对冲掉"理想主义陷阱"
- 但他不是**人生规划师**，是**就业咨询师**——目标不同，结论不同
- 他的建议**有效期 3-5 年**，因为产业变化太快，今天的热门可能是明天的过剩

### 正确用法

| 做法 | 说明 |
|------|------|
| ✅ 听他的**避坑逻辑** | 哪些专业谨慎 |
| ❌ 别照搬他的**具体推荐** | 计算机/法学已经卷爆了 |
| ✅ 结合**家庭条件 + 个人特质 + 行业趋势** | 做综合判断 |

---

## 📻 一句话总结

**张雪峰是普通家庭的"防御性报考策略"——不能保证你赢，但能保证你不输得太惨。**

但如果你想追求上限，而不是保底，那他的建议可能反而会限制你。
